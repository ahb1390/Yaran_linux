01 // نسخه‌ها و دریافت

نسخهٔ مناسب کار خود را انتخاب کنید

سه تصویر آمادهٔ دریافت در کنار نسخهٔ توسعه‌ای Extended؛ مشخصات هر نسخه و راه‌های دریافت یا ساخت آن در ادامه آمده است.

تمام انتشارها
نسخهٔ پیشنهادی

Desktop Minimal

AMD64 // x86_64

یک دسکتاپ کامل و متعادل برای استفادهٔ روزمره؛ با KDE Plasma، مرورگرها و مجموعه‌ای از برنامه‌های کاربردی اصلی.

  • Firefox ESR · Google Chrome
  • LibreOffice · VLC · Telegram
  • نصب‌کنندهٔ گرافیکی Calamares
دانلود ISOفایل checksum (SHA-256)

ساخت شخصی

Desktop Extended

AMD64 // x86_64

مناسب توسعه، طراحی و مجازی‌سازی؛ شامل امکانات نسخهٔ Minimal به‌همراه ابزارهایی مانند GIMP، VirtualBox، VSCodium و ابزارهای برنامه‌نویسی.

  • GIMP · Obsidian · VSCodium
  • ابزارهای توسعه و ساخت نرم‌افزار
  • VirtualBox · DKMS · Linux headers
چرا ISO آماده نیست؟ حجم تصویر از سقف مجاز هر فایل در GitHub Releases بیشتر است. مانیفست و کد ساخت عمومی‌اند؛ می‌توانید تصویر را در میزبان Linux با معماری AMD64 بسازید. ساخت موفق، ISO و فایل checksum از نوع SHA-256 را در پوشهٔ خروجی تولید می‌کند.
$python3 build.py Yaran-2.0-amd64-extended.json --validate
$sudo python3 build.py Yaran-2.0-amd64-extended.json --workdir build-extended --outdir output-extended
راهنمای رسمی ساختمشاهدهٔ مانیفست ساخت (JSON)
پیش از اجرای دستور ساخت، پیش‌نیازهای میزبان را در راهنمای رسمی نصب کنید. ساخت کامل به دسترسی مدیریتی نیاز دارد.

Desktop ARM64

  • KDE Plasma · Calamares
  • ساخت روی معماری بومی ARM64
  • نیازمند دستگاه سازگار با بوت UEFI است

Yaran Server

AMD64 // x86_64

نسخه‌ای برای زیرساخت و سرویس‌ها، بدون دسکتاپ گرافیکی؛ با ابزارهای شبکه، مدیریت سیستم و نصب‌کنندهٔ متنی راهنما.

  • Podman · Storage utilities
  • ابزارهای شبکه، پایش و امنیت
  • نصب‌کنندهٔ CLI با تأیید صریح پیش از پاک‌سازی دیسک

02 // اصول پروژه

ساختار روشن؛ انتخاب آگاهانه

هدف، ارائهٔ تصویری قابل بررسی و قابل ساخت است؛ با مرزبندی روشن میان نسخه‌های آماده، فایل‌های پیکربندی و فرایند ساخت.

پایهٔ Debian 13

بر پایهٔ Debian 13 (Trixie)، با مخازن مربوط به به‌روزرسانی و امنیت.

KDE Plasma

محیط دسکتاپ آشنا و کامل با ابزارهای اصلی شبکه، صدا، بلوتوث و مدیریت سیستم.

ساخت و راستی‌آزمایی

مانیفست‌های JSON، ابزار ساخت عمومی و checksumهای SHA-256 کمک می‌کنند فرایند ساخت و صحت دانلودها بررسی‌پذیر باشد.

03 // مستندات و منبع

پیش از نصب یا ساخت، مستندات را بخوانید

راهنمای ساخت، مانیفست نسخه‌ها، معماری پروژه و راهنمای عیب‌یابی در مخزن عمومی قرار دارند. ساخت تصویر کامل با دسترسی مدیریتی انجام می‌شود؛ پیش از اجرا، پیش‌نیازها و کدهای ساخت را بازبینی کنید.

$ cd Yaran_linux
